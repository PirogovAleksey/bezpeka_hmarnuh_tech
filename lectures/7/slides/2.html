Тема 7.2: Основні функції CSPM

П'ять ключових функцій

1
Виявлення активів (Discovery)
2
Оцінка конфігурацій (Assessment)
3
Пріоритезація ризиків
4
Моніторинг відповідності
5
Усунення порушень (Remediation)

Виявлення та оцінка (1–2)

  • Інвентаризація активів: ВМ, контейнери, serverless, об'єктне сховище, IAM-ролі, мережі
  • Оновлення у реальному часі: опитування API (polling) + події хмари (event-driven)
  • Оцінка проти CIS Benchmarks AWS/Azure/GCP, AWS Well-Architected
  • Фреймворки відповідності: PCI DSS, HIPAA, SOC 2, GDPR
  • Власні політики організації (наприклад, через OPA/Rego)

Пріоритезація ризиків (3)

  • Критичність (severity): публічна експозиція проти внутрішньої помилки
  • Придатність до експлуатації (exploitability): наскільки легко атакувати
  • Важливість активу (asset criticality): продакшн проти dev-середовища
  • Аналіз шляхів атаки (attack path analysis): чи існує ланцюг до чутливих даних

Відповідність та усунення (4–5)

  • Безперервний моніторинг: дашборди, автоматизовані звіти, аналіз розривів
  • Збір доказів для аудиторського журналу
  • Ручні інструкції для операторів (manual guidance)
  • Напівавтоматичне: згенеровані CLI-команди та IaC-виправлення
  • Превентивне: блокування небезпечних розгортань у CI/CD

Розширення функцій у сучасних CSPM

  • CIEM: аналіз IAM-прав, виявлення надмірних привілеїв та неактивних ідентичностей
  • DSPM: пошук чутливих даних, моніторинг шифрування
  • Мережева безпека: візуалізація топології, аналіз експозиції в інтернет
  • Attack Path: моделювання реальних ланцюгів компрометації

Ключові висновки

  • CSPM — це п'ять функцій: виявлення, оцінка, пріоритезація, відповідність, усунення
  • Інвентаризація без пріоритезації створює втому від сповіщень (alert fatigue)
  • Пріоритезація за шляхами атаки — ключова відмінність сучасних платформ
  • CSPM еволюціонує у бік уніфікації з CIEM, DSPM та CWPP (CNAPP)
